Apresentação profissional

Esta estrutura foi pensada para funcionar como página inicial do GitHub Pages, apresentando de forma clara quem você é, como utiliza o repositório institucionalmente e quais temas os estudantes podem acessar com um clique.

Ela também abre espaço para futura expansão com novas seções, como projetos de pesquisa, extensão, publicações, materiais de aula e uma galeria de fotografia.

Sugestões de expansão

Adicionar seção de fotografia com miniaturas e link para portfólio visual.
Separar disciplinas por nível: técnico, graduação e pós-graduação.
Inserir links para currículo, Lattes, projetos de pesquisa e contato institucional.
Criar âncoras por tema para facilitar o acesso dos alunos em dispositivos móveis.

Página pronta para uso em GitHub Pages. Para publicar, renomeie o arquivo para index.html no repositório destinado à página pessoal.
